# AWS学習ゲーム v3 仕様書

## 1. シリーズの核

v1/v2から引き継ぐ最小コンセプトは「AWSサービスを、案件要件に合わせて選び、その選択理由を学ぶゲーム」である。

- 案件・障害・制約を読み、適切なAWSサービスを選ぶ
- 機能、可用性、セキュリティ、性能、コスト、運用負荷の6軸で良し悪しを返す
- AWSサービス名、役割、向き不向き、組み合わせを自然に覚える
- ダークUI、青系アクセント、日本語、軽い絵文字でシリーズの雰囲気を保つ
- 最後に「なぜ正解/失点なのか」を短く返して復習できる

## 2. v2の問題点分析

v2は現実味が強い一方で、ゲームとしてのテンポが落ちやすい。

- 案件要件がRPS、SLA、予算、静的比率、イベントまで多く、読み始めの負荷が高い
- 6レイヤーに多数のAWSサービスを配置するため、1手ごとの意味は深いが判断回数が多い
- 30日シミュレーションの待ち時間があり、プレイヤーが操作しない時間が発生する
- 結果指標がコスト、SLA、平均応答、エラー率、停止日数に分かれ、失敗理由の把握に時間がかかる
- リトライ時も再配置の手数が多く、短い試行錯誤のループになりにくい

v3では「現実的な構成をじっくり作る」よりも「要件からAWSサービスを即断する」体験に振り切る。

## 3. v3のコンセプト一言、ターゲット体験

コンセプト: **AWSサービスを数秒で選び、即採点されるクラウド設計スプリント。**

ターゲット体験:

- 1問ごとに「この状況なら何を使う？」を素早く判断する
- 選んだ瞬間に候補の役割が見え、提出後すぐ正誤と理由が返る
- 失敗しても即リトライでき、同じAWS語彙に短時間で何度も触れる
- v1/v2の6軸思想は残しつつ、数値シミュレーションは簡略化する

## 4. ゲームの基本ループ

- 1ラウンドは8〜14秒を想定
- 1ラウンドで案件カードを1枚表示する
- プレイヤーは8個の候補サービスから最大3個を選ぶ
- 「提出」または時間切れで即採点する
- 結果画面ではランク、軸別評価、正解サービス、短い解説を表示する
- 「次へ」で即次ラウンドへ進む
- 1プレイは8ラウンド、2〜4分程度で終了する
- 最終結果は合計スコア、最高連続正解、苦手軸、復習サービスを返す

## 5. プレイヤーアクション、フィードバックの即時性

プレイヤーアクション:

- 候補サービスをクリックして選択/解除する
- 最大3個まで選択する
- 提出ボタンで採点する
- 結果から次ラウンドまたはリトライに進む

即時フィードバック:

- サービスカード選択時にカードが強調される
- 選択中のサービス数と提出可否が即更新される
- 提出直後にランク、点数、6軸バー、正解/不足/余計な選択を表示する
- 重要なシナジーは「S3 x CloudFront」のように短く表示する
- 結果画面から1クリックで次へ進める

## 6. 学習効果の担保

学習効果は長い説明ではなく、短い反復で担保する。

- 各案件に「狙いのAWSサービス」を設定し、要件とサービス名を対応付ける
- サービスごとに役割、タグ、6軸への寄与を持たせる
- 採点後に「なぜそのサービスが合うか」を1〜3行で表示する
- 不足サービスと余計なサービスを明示し、誤選択の修正先を示す
- 最終結果で苦手軸と復習すべきサービスを表示する

## 7. 既存2作との差別化マトリクス

| 項目 | v1 Cloud Deck Architect | v2 Cloud Architect Simulator | v3 Cloud Sprint Architect |
| --- | --- | --- | --- |
| 主体験 | デッキ構築ローグライク | 現実的な構成設計と30日観察 | 数秒判断のサービス選択 |
| 1プレイ | 15案件で長め | 1案件ごとにじっくり | 8ラウンドで短い |
| 1ラウンド | 手札から最大4枚 | 6レイヤーに自由配置 | 候補8枚から最大3枚 |
| 評価 | 6軸スコア、SP、報酬 | SLA/コスト/応答など現実指標 | 6軸を簡略表示、即ランク |
| 学習 | カード効果とシナジー | アーキテクチャ全体の現実感 | サービス用途の瞬間認識 |
| テンポ | 中速 | 低速 | 高速 |
| リトライ | ラン全体の再挑戦 | 構成再配置が必要 | 1クリックで即再走 |
| 引き継ぐ核 | AWS語彙、案件、6軸 | 現実的な要件語彙 | AWS語彙、案件、6軸、短い解説 |
